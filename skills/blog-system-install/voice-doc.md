# Voice doc, starting template

`blog-system-install` fills this in from real writing samples the owner provides,
then writes it into their Drive folder. `blog-writer` reads it before every draft
and treats it as the authority.

The goal is **reproducible patterns**, not compliments. "Warm and professional"
tells a writer nothing. "Opens with a question, never uses exclamation points,
calls customers guests rather than clients" tells a writer everything.
